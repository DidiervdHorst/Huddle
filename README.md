# huddle

A visual prototype for **Huddle** — an app that makes meeting up with friends spontaneous again.

Built with React, TypeScript, Tailwind CSS, and Framer Motion. Styled as an iOS-style mobile app: soft multi-color gradients, glassmorphism, rounded corners, and playful micro-animations. All data is mocked — there's no backend, auth, or persistence.

## Screens

- **Home** — greeting, one-tap mood/activity buttons, live friend activity feed
- **Create Huddle** — a bottom sheet to start a huddle in seconds, everything optional
- **Activity** — who's free right now, recent joins and messages
- **Profile** — availability toggle (Free / Maybe / Busy), interests, friends

## Run locally

```bash
npm install
npm run dev
```

The app renders inside a phone frame in the browser — best viewed at a mobile viewport width.
